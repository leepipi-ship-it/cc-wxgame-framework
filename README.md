# 微信小游戏框架启动模板

基于 Cocos 引擎构建的微信小游戏框架启动模板，用于快速搭建微信小游戏项目的基础架构。

## 项目特点

- 非加密、非混淆的可读代码
- 不含游戏业务逻辑，仅保留核心框架
- 清晰的模块化架构设计
- 支持动态模块加载
- 适配微信小游戏环境
- 包含完整的启动流程

## 目录结构

```
├── cocos-js/                  # Cocos 引擎核心文件

│   └── cc.js                  # Cocos 引擎主模块
├── subpackages/               # 微信小游戏分包目录
│   ├── app-admin/             # 管理员功能模块
│   ├── app-manager/           # 应用管理模块
│   ├── app-model/             # 数据模型模块
│   ├── app-sound/             # 音频管理模块
│   ├── page-home/             # 首页模块
│   ├── page-home-res/         # 首页资源模块
│   ├── page-main/             # 主页面模块
│   ├── page-main-res/         # 主页面资源模块
│   ├── pop-quit/              # 退出弹窗模块
│   ├── pop-quit-res/          # 退出弹窗资源模块
│   ├── pop-rank/              # 排行榜弹窗模块
│   ├── pop-rank-res/          # 排行榜弹窗资源模块
│   ├── pop-result/            # 结果弹窗模块
│   ├── pop-result-res/        # 结果弹窗资源模块
│   ├── pop-setting/           # 设置弹窗模块
│   ├── pop-setting-res/       # 设置弹窗资源模块
│   ├── pop-share/             # 分享弹窗模块
│   ├── pop-share-res/         # 分享弹窗资源模块
│   ├── pop-skin/              # 皮肤弹窗模块
│   ├── pop-skin-res/          # 皮肤弹窗资源模块

├── engine-adapter.js          # 引擎适配器

├── game.js                    # 游戏主入口
└── web-adapter.js             # Web 环境适配器
```

## 核心功能

1. **游戏启动流程**
   - 初始化环境
   - 配置画布尺寸
   - 加载系统模块
   - 启动引擎
   - 初始化应用

2. **模块加载机制**
   - 基于 SystemJS 的动态模块加载
   - 支持插件和项目模块

3. **适配处理**
   - Web 环境适配
   - 微信小游戏环境适配
   - 不同设备分辨率适配

4. **性能优化**
   - 设备像素比处理
   - 启动进度管理

## 使用方法

### 1. 启动项目

```bash
使用微信开发者工具打开项目目录
```

### 2. 开发流程

1. 在 `subpackages/` 目录下创建新的功能模块
2. 在 `application.js` 中扩展应用功能
3. 通过 `System.import()` 动态加载模块
4. 使用微信开发者工具进行调试

## 核心代码说明

### game.js
游戏主入口文件，负责：
- 初始化环境
- 配置画布尺寸
- 加载系统模块
- 启动应用程序

### application.js
应用程序类，负责：
- 引擎初始化
- 系统事件处理
- 应用启动管理

### engine-adapter.js
引擎适配器，负责：
- 微信小游戏环境适配
- 引擎模块加载
- 资源管理适配

### web-adapter.js
Web 环境适配器，负责：
- Web 环境兼容处理
- 模块加载机制适配


## 注意事项

1. 本项目仅包含框架启动代码，不包含具体游戏业务逻辑
2. 需要配合 Cocos 引擎使用
3. 适用于微信小游戏环境
4. 支持动态分包加载
5. 可以根据需求扩展功能模块
